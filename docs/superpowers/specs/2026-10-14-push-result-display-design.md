# 一键推送结果展示设计

## 目标

让 Windows 本地“一键推送”在任何启动器或终端配置下，都能明确告知用户推送成功或失败，不再依赖控制台窗口和 `pause`。

## 设计

1. 移除当前二次启动 `cmd` 的托管逻辑，推送流程在调用进程内执行。
2. 一键模式不等待控制台输入；有变更时使用 `ALPHACORE_COMMIT_MSG`，未提供则使用 `update: daily update`。
3. 每次执行都覆盖写入 `%TEMP%\AlphaCore\latest-push-result.txt`，内容包括完成时间、总体结果、两个仓库状态、推送数和错误数。
4. 交互模式完成后用记事本打开报告；`ALPHACORE_PUSH_NO_PAUSE=1` 时只写报告、不打开界面。
5. 成功报告包含阿里云部署命令；失败报告明确要求查看控制台或重新运行排查。

## 错误处理

- Git 缺失、仓库异常、远端失败和推送校验失败均汇总到同一报告。
- 报告目录创建失败时，控制台显示明确错误，但不覆盖原始推送退出码。
- 记事本启动失败时显示报告绝对路径，供用户手动打开。

## 验证

- 静态测试确认脚本不再创建隐藏托管控制台，也不再要求提交信息输入。
- 无网络副作用地隐藏 Git，验证失败报告被创建且包含 `FAILED` 和仓库状态。
- 验证自动化模式不启动记事本，原有安全测试全部通过。
